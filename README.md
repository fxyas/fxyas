## 🤖 About me

I'm a **robotics software engineer** who likes taking robots out of simulation and onto the floor.
I work across the whole stack: microcontroller firmware and sensors, ROS 2 drivers, navigation and
SLAM, camera calibration, and the tools operators use to run the robot.

- 🚚 **Now:** building an industrial **autonomous mobile robot (AMR)**: Nav2 tuning, LiDAR + depth-camera
  obstacle avoidance, docking, battery (BMS) integration, robot health diagnostics and a web operator console
- 🦾 **Also:** robot-arm vision: hand-eye calibration and ArUco-guided grasp targets
- 💬 **Ask me about:** ROS 2, Nav2 parameter tuning, SLAM, TF trees, PID control, ESP32 / Arduino

`ROS 2` `PID` `Arduino` `IMU`
